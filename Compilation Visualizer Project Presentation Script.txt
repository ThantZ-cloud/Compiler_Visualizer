Compilation Visualizer Project Presentation Script
၁။ နိဒါန်းနှင့် Compiler ၏ အရေးပါပုံ (၀:၀၀ - ၀:၄၅)
ဒီနေ့ခေတ်မှာ ကျွန်တော်တို့ အသုံးပြုနေတဲ့ အင်တာနက်၊ ဖျော်ဖြေရေး၊ လုံခြုံရေးနဲ့ အိမ်သုံးပစ္စည်းတွေမှာပါဝင်တဲ့ software အားလုံးဟာ ကွန်ပျူတာပရိုဂရမ်တွေအပေါ်မှာ မှီခိုနေရတာဖြစ်ပါတယ်
။ ဒီ software တွေအားလုံးနီးပါးကို Compiler လို့ခေါ်တဲ့ ကိရိယာနဲ့ ဘာသာပြန်ဆိုထားတာ ဖြစ်ပါတယ်
။ Compiler ဆိုတာ ပရိုဂရမ်မာတွေ ရေးသားထားတဲ့ High-level language တွေကို ကွန်ပျူတာ hardware က နားလည်နိုင်တဲ့ Machine operations ဒါမှမဟုတ် Machine Code အဖြစ် ပြောင်းလဲပေးတဲ့ software တစ်ခု ဖြစ်ပါတယ်
။
၂။ Compiler ဘာကြောင့်လိုအပ်သလဲနှင့် အလုပ်လုပ်ပုံ (၀:၄၅ - ၁:၃၀)
လူသားတွေဟာ တွက်ချက်မှုတွေကို ဖော်ပြဖို့အတွက် programming language တွေကို အသုံးပြုကြပေမယ့် hardware processor တွေကတော့ Machine Code ဒါမှမဟုတ်  binary operations  - 1,0 တွေကိုပဲ တိုက်ရိုက်လုပ်ဆောင်နိုင်တာပါ
။ ဥပမာအားဖြင့်- စာသားတစ်ခုကို print ထုတ်ဖို့ ရေးထားတဲ့ code တစ်ကြောင်းဟာ စက်ထဲမှာ တကယ်အလုပ်လုပ်ဖို့ machine operations ရာပေါင်းများစွာအဖြစ် ပြောင်းလဲဖို့ လိုအပ်ပါတယ်
။ ခေတ်မီ compiler တစ်ခုကို အပိုင်း (၃) ပိုင်းနဲ့ ဖွဲ့စည်းထားလေ့ရှိပါတယ်- source code ကို နားလည်အောင်လုပ်တဲ့ Front End၊ code ကို ပိုကောင်းအောင်လုပ်တဲ့ Optimizer နဲ့ target machine  အတွက် code ထုတ်ပေးတဲ့ Back End တို့ ဖြစ်ကြပါတယ်
။
၃။ Project ၏ ရည်ရွယ်ချက်နှင့် လုပ်ဆောင်ချက်များ (၁:၃၀ - ၂:၁၅)
Compiling Technique ဘာဿာရပ်ဟာ computer science ရဲ့ အခက်ခဲဆုံး ဘာသာရပ်တွေထဲမှာ တစ်ခုအပါအဝင် ဖြစ်ပါတယ်
။ ဒါကြောင့် ဒီခက်ခဲတဲ့ compiler internals တွေကို ကျောင်းသားတွေနဲ့ developer တွေ နားလည်လွယ်စေဖို့ "Compilation Visualizer" project ကို web-based application တစ်ခုအနေနဲ့ ဖန်တီးခဲ့တာပါ
။ ဒီ project မှာ အသုံးပြုသူက Java code ကို တိုက်ရိုက်ရေးသားနိုင်ပြီး compilation အဆင့်ဆင့်ကို animated UI တွေနဲ့ လေ့လာနိုင်သလို၊ code ရဲ့ ရလဒ်ကိုလည်း တိုက်ရိုက် execution လုပ်ပြနိုင်မှာ ဖြစ်ပါတယ်
။ ဒီ project အတွက် အသုံးပြုထားတဲ့နည်းပညာတွေကတော့ Frontendအတွက် React, Backend အတွက် Spring Bootတို့ကို အသုံးပြုထား‌ပါတယ်။ 
Backend မှ JavaLexer နှင့် JavaParser တို့ဖြင့် Source Code မှ Tokens, AST, Symbol Table နှင့် CFG တို့ကို ခွဲထုတ်ပြီး Frontend မှာ D3.js နှင့် Three.js တို့ဖြင့်  2D/3D Visual အဖြစ် ပုံဖော်ပြသပေးထားပါတယ်။
။
၄။ Visualizer ၏ အဆင့်ဆင့် လုပ်ဆောင်ပုံများ (၂:၁၅ - ၄:၁၅)
ကျွန်တော်တို့ visualizer ထဲမှာ အဓိက အဆင့် (၆) ဆင့်ကို ပုံဖော်ပြသထားပါတယ်
။
Lexical Analysis: ပထမဆုံးအဆင့်မှာ source code ထဲက character တွေကို token တွေအဖြစ် ပြောင်းလဲပေးပါတယ်
။ ကျွန်တော်တို့ရဲ့ Visualizer မှာ Regular Expressions ကနေ NFA, DFA အဆင့်ဆင့် ပြောင်းလဲပုံကို အန်နီမေးရှင်းတွေနဲ့ မြင်တွေ့ရမှာပါ
။
Syntax Analysis: ဒီအဆင့်မှာတော့ tokens တွေဟာ grammar စည်းမျဉ်းနဲ့ ကိုက်ညီမှုရှိမရှိ စစ်ဆေးပြီး Abstract Syntax Tree (AST) ကို D3.js နဲ့ တည်ဆောက်ပြထားပါတယ်
။
Semantic Analysis: ဒီနေရာမှာတော့ ပရိုဂရမ်ရဲ့ အဓိပ္ပာယ်ကို စစ်ဆေးပါတယ် (ဥပမာ- type checking)
။ Visualizer ကနေ Symbol Table တွေ တည်ဆောက်ပုံကို ပြသပေးမှာပါ
။
Optimizer: ၎င်းသည် code ကို မပြောင်းလဲစေဘဲ ပိုမိုမြန်ဆန်ပြီး ထိရောက်တဲ့ code ဖြစ်အောင် IR-to-IR transformation တွေ လုပ်ဆောင်ပေးပါတယ်
။
Code Generation: နောက်ဆုံးမှာတော့ optimizer က ထွက်လာတဲ့ IR ကို target machine ရဲ့ instruction set တွေအဖြစ် ပြောင်းလဲပေးပါတယ်
။
Bytecode: Java အတွက်ဆိုရင်တော့ source code ကို compact ဖြစ်တဲ့ Bytecode အဖြစ် ပြောင်းလဲပြီး Java Virtual Machine (JVM) ပေါ်မှာ run ဖို့ ပြင်ဆင်ပေးပါတယ်
။
၅။ နိဂုံး (၄:၁၅ - ၅:၀၀)
ဒီ project ဟာ compiler တစ်ခုရဲ့ ရှုပ်ထွေးလှတဲ့ algorithms တွေ theoryတွေ စတာတွေကို step by step ကြည့်ရှုလို့ရအောင် လုပ်ဆောင်ပေးနိုင်ပါတယ်
။  ဒါကြောင့်ဒီ"Compilation Visualizer" project ဟာ software အင်ဂျင်နီယာကောင်းတစ်ယောက် ဖြစ်ဖို့အတွက် မရှိမဖြစ်လိုအပ်တဲ့ compiler သဘောတရားတွေကို အလွယ်ကူဆုံး လေ့လာနိုင်မယ့် ပလက်ဖောင်းတစ်ခု ဖြစ်ပါတယ်
